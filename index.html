CBIT Customer Toolkit

Public scripts-only technician toolkit, currently at v0.3.4-rc11.

Run in a PowerShell window on a customer computer (run elevated on the DC/package host for GPO deployment):

irm https://cbit-msp.github.io/cbit.txt | iex

SentinelOne deployment asks for the CBIT deployment unlock passphrase. Obtain it from your approved technician vault.

The short command checks the downloaded loader and toolkit package against fixed SHA-256 hashes. See the release page for asset hashes. For an independent first-stage check, use the hash-pinned verification command distributed through your trusted technician channel.
